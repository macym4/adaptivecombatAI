**What is FABRIK?**

FABRIK is an inverse kinematics algorithm that utilizes repeated forward and backward passes to reach a set of joint and points to a target position.

**How did you implement the algorithm?**

The paper that I took the direct algorithm pseudocode from can be found at this link and is cited in MLA below: https://www.andreasaristidou.com/publications/papers/FABRIK.pdf.

Aristidou, A., & Lasenby, J. (2011). FABRIK: A fast, iterative solver for the inverse kinematics problem. Graphical Models, 73(5), 243–260. https://doi.org/10.1016/j.gmod.2011.05.003
